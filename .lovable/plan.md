# Стаканы: выдача до смены, свои типы, сверка в конце

## Что появится

**1. Управление типами стаканов (админ)**
Новый раздел «Стаканы» в админке: список всех типов (Крафт 350/450, Пластик 500/700 и любые новые). Админ может добавить новый тип — название, материал (крафт/пластик/другое), объём в мл, порядок в списке — переименовать, изменить объём или скрыть неиспользуемый.

**2. Выдача стаканов до открытия смены**
Админ выбирает кассира (или филиал) и дату, вводит количество по каждому типу и сохраняет заготовку выдачи. Когда кассир открывает смену в этот день, выданные количества автоматически подставляются в его смену — ничего дополнительно делать не нужно. Уже открытой смене выдачу по-прежнему можно поправить вручную.

**3. Экран кассира «Стаканы»**
Таблица по каждому типу: выдано в начале смены / использовано (считается по проданным товарам, привязанным к этому стакану, с учётом размера) / остаток. В конце смены кассир вводит фактический пересчёт по каждому типу и видит расхождение (факт − расчётный остаток). Тот же блок появляется в окне закрытия смены, чтобы кассир не забыл пересчитать.

**4. Просмотр у админа**
В истории смен по каждой смене — раскрывающийся блок со стаканами: выдано, использовано, факт, расхождение. Расхождения подсвечиваются. Данные попадают в Excel- и PDF-экспорт смены.

## Офлайн

Типы стаканов и выдачи кэшируются локально, расход считается из локальных чеков, ввод пересчёта уходит в очередь и синхронизируется при появлении сети — как сейчас.

## Техническая часть

- Миграция: таблица `cup_allocations` (branch_id, cashier_id, for_date, cup_type_id, qty, created_by, timestamps, уникальность по кассир+дата+тип) с GRANT и RLS — админ полный доступ, кассир читает свои. Разрешить админу INSERT/UPDATE/DELETE в `cup_types` уже есть; добавить недостающие поля не нужно.
- При открытии смены (`shifts.functions` / offline-путь в `AppShell.tsx`) переносить строки `cup_allocations` за сегодняшнюю дату в `shift_cups.issued_qty`.
- Dexie v8: стор `cupAllocations`; `src/lib/cups.ts` — функции `listAllocations`, `saveAllocation`, `applyAllocationsToShift`, CRUD типов стаканов.
- UI: новая страница `/_authenticated/admin.cups` (типы + выдача на дату), блок стаканов в диалоге закрытия смены в `AppShell.tsx`, расширение раздела в `admin.shifts.tsx`, колонки в `export-excel.ts` и `export-pdf.ts`.
