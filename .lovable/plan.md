
## 1. Смены работников (расписание админа)

- Новая таблица `shift_schedules`: `worker_id`, `branch_id`, `starts_at`, `ends_at`, `note`. RLS: админ управляет, кассир видит свои.
- Страница `/admin/shifts` расширяется вкладками: **«Расписание»** (админ создаёт слоты на работника с датой/временем) и уже существующая **«Факт»** (открытые/закрытые смены).
- В карточке запланированной смены админ видит агрегат по фактически проведённой смене работника, попадающей в интервал: количество чеков, выручка, наличные/карта, прибыль.
- У кассира в сайдбаре под кнопкой «Открыть смену» добавляется мини-блок «Ближайшая смена: пт 18:00–23:00».

## 2. Свободный чек в POS

Две кнопки над корзиной:
- **«+ Позиция»** — диалог: название, цена, кол-во → добавляется строкой с `product_id = null`, `variant_size = null`.
- **«Чек суммой»** — диалог: одна сумма → создаёт корзину из одной строки «Произвольная продажа» с этой ценой.

В `sale_items` `product_id` уже nullable, триггер `apply_sale_item` игнорирует null — миграция не нужна для схемы, только правки UI и синка (уже поддерживает null).

## 3. Просмотр и редактирование чека

Страница `/receipts` (уже существует) получает клик по карточке → диалог **«Состав чека»**:
- Список позиций: название, размер, кол-во, цена, сумма. Доступно и кассиру, и админу (кассир видит только свои — RLS уже так настроен).
- Для админа в этом диалоге:
  - Редактировать кол-во/цену строки.
  - Удалить строку.
  - Удалить весь чек.
  - При изменении/удалении: пересчёт `total`, откат `products.stock` и `sales_count` для затронутых позиций через серверную функцию.

Серверные функции (`src/lib/sales.functions.ts`):
- `getSaleDetail({ sale_id })` — сам чек + позиции.
- `updateSaleItem({ item_id, qty, unit_price })` — только админ, пересчёт склада и итога.
- `deleteSaleItem({ item_id })` — только админ.
- `deleteSale({ sale_id })` — только админ, полный возврат склада.

Все проверяют `has_role(auth.uid(),'admin')`.

## 4. Упаковка в Android APK через Capacitor

Что делаю в коде:
- `bun add @capacitor/core @capacitor/cli @capacitor/android`.
- `capacitor.config.ts` c `appId=com.gottistuff.pos`, `appName=Gotti Stuff`, `webDir=dist`, `server.androidScheme=https`.
- В `vite.config.ts` сборка в `dist/`; SPA-режим для Capacitor (SSR отключается для мобильной сборки — используется опубликованный статический билд).
- README-инструкция в `MOBILE.md` с командами: `bun run build`, `npx cap add android`, `npx cap sync`, `npx cap open android`, сборка APK в Android Studio.

## Что мне нужно от тебя

Собрать APK нужно на твоём компьютере (в облаке Lovable Android SDK нет). Для этого установи:
1. **Node.js 20+** и **bun** (или npm).
2. **Android Studio** (последняя версия) — скачай с developer.android.com/studio.
3. **JDK 17** (обычно ставится с Android Studio).
4. После моих правок: экспортируй проект в GitHub (кнопка справа сверху в Lovable), клонируй его локально, `bun install`, дальше по `MOBILE.md`.

Скажи, если нужен ещё какой-то нюанс (иконка приложения, splash-скрин, конкретный `appId`, поддержка планшетной ориентации только landscape) — включу в план.
