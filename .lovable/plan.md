# Учёт стаканов (крафт 350/450, пластик 500/700)

## Что появится

**1. Справочник стаканов**
Четыре типа: Крафт 350, Крафт 450, Пластик 500, Пластик 700. Админ может добавлять/переименовывать типы.

**2. Настройка у каждого товара**
В карточке товара — выбор типа стакана. Если у товара есть размеры (M/L), тип стакана задаётся отдельно для каждого размера (например M → Крафт 350, L → Крафт 450). Кофе и горячее — крафт, холодные напитки — пластик.

**3. Выдача стаканов на смену**
Админ при открытии/во время смены кассира указывает, сколько стаканов каждого типа выдано. Кассир видит это у себя.

**4. Экран «Стаканы» у кассира**
Таблица по каждому типу: выдано / использовано / остаток. Использовано считается автоматически: каждая проданная позиция списывает 1 стакан своего типа (умножается на количество). Работает офлайн — считается из локальных чеков.

**5. Сверка в конце смены**
При закрытии смены кассир вводит фактический остаток по каждому типу. Приложение показывает расхождение (факт − расчётный остаток). Админ видит сверку в истории смен и в дашборде, расхождения попадают в Excel/PDF-экспорт.

## Офлайн и скорость

- Типы стаканов и выдачи кэшируются в локальной базе, экран открывается мгновенно без интернета.
- Использование считается из уже закэшированных чеков, без запросов к серверу.
- Ввод сверки офлайн ставится в очередь и уходит на сервер при появлении сети (как смены и приходы).

## Техническая часть

- Миграции: таблица `cup_types` (name, material, volume_ml), колонка `cup_type_id` у `products` и поле `cup_type_id` внутри JSON `sizes`, таблица `shift_cups` (shift_id, cup_type_id, issued_qty, counted_qty, created_at/updated_at). GRANT + RLS: админ — полный доступ, кассир — чтение типов, чтение своих `shift_cups` и обновление `counted_qty` своей смены.
- Dexie v7: сторы `cupTypes`, `shiftCups`, очередь `pendingCupCounts`; синк добавляется в `src/lib/sync.ts`.
- Расход считается на клиенте по `saleItems` смены: позиция → товар/размер → тип стакана → сумма `qty`.
- UI: поле «Стакан» в `products.tsx` (и в строках размеров), новая страница `/_authenticated/cups` для кассира, блок выдачи в `admin.shifts.tsx`, колонки сверки в `admin.index.tsx` и в экспортах `export-excel.ts` / `export-pdf.ts`.
