## Что сделаю

Настрою GitHub Actions workflow, который при каждом push в `main` (и по кнопке вручную) собирает Android APK приложения Gotti Stuff и публикует его в GitHub Releases — оттуда качаешь готовый `.apk` по прямой ссылке и ставишь на планшет.

Локально ничего ставить не надо — вся сборка идёт на серверах GitHub бесплатно.

## Что появится в репозитории

1. **`.github/workflows/android-build.yml`** — сам workflow:
   - ставит Node/Bun, JDK 17, Android SDK
   - `bun install` → `bun run build` (веб-сборка)
   - `bunx cap sync android`
   - `./gradlew assembleDebug` (debug APK — ставится без Google Play, без подписи от разработчика)
   - публикует APK как артефакт сборки **и** создаёт GitHub Release с прикреплённым `.apk`
2. **`android/`** — папка Android-проекта (Capacitor). Сейчас её в репо нет, добавлю через `cap add android` внутри workflow либо закоммичу локальный скелет — сделаю так, чтобы папка была в репо (нужно для стабильной сборки и иконки/имени приложения).
3. **Иконка и splash-скрин** приложения Gotti Stuff (простая, на базе текущей темы) — чтобы на планшете иконка была нормальная, а не дефолтная зелёная от Capacitor.

## Как ты получишь APK

После того как я всё закоммичу:

```text
GitHub репо → вкладка Actions → последний запуск "Android Build" →
   ├── Artifacts (внизу страницы) → app-debug.apk  ← можно скачать сразу
   └── Releases (в правой колонке репо) → v-<номер> → app-debug.apk  ← прямая ссылка
```

Ссылка на релиз будет постоянной, вида:
`https://github.com/<твой-логин>/<репо>/releases/latest`

Открываешь её с планшета → скачиваешь `app-debug.apk` → разрешаешь «Установка из неизвестных источников» → ставится Gotti Stuff.

## Важные оговорки

- **Debug APK, не Play Store.** Он подписан отладочным ключом Android — этого хватит, чтобы поставить на любой планшет вручную. Для публикации в Google Play нужен отдельный подписанный `.aab` и аккаунт разработчика ($25) — это отдельная задача, скажи если нужно.
- **Первая сборка ~5–8 минут** (потом ~3 мин), потому что скачивается Android SDK.
- **Приложение будет ходить в тот же Supabase**, что и веб-версия — те же логины кассиров, те же данные, те же филиалы. Отдельная база не нужна.
- **Оффлайн-режим уже работает** (Dexie + фоновая синхронизация), в APK он тоже будет работать.
- **Дать прямую ссылку прямо сейчас я не могу** — она появится после первого успешного запуска workflow в твоём репо. Как только зальётся — ссылка будет `.../releases/latest` в твоём GitHub.
