
## Что добавляем

### 1. Отложенный чек («Ожидание»)
- Кнопка **«В ожидание»** в POS рядом с «Оплатить». Сохраняет текущую корзину (товары, размеры, кол-во) в локальный список отложенных с меткой (имя клиента / номер стола — короткое поле).
- В шапке POS — счётчик отложенных и выпадашка «Ожидание (N)». Клик по чеку возвращает корзину в кассу; можно удалить.
- Хранение: локально в Dexie (переживает офлайн/перезагрузку планшета) + опционально синк в новую таблицу `parked_sales` для админа.

### 2. Открытие смены с остатком (opening cash)
- При нажатии «Открыть смену» — модалка **«Остаток в кассе»**, ввод суммы наличных на старте. Без ввода смена не открывается.
- При закрытии — модалка **«Итог по кассе»**: показывает `opening_cash + продажи налом − возвраты`, поле «Факт в кассе», авторасчёт расхождения. Всё пишется в `shifts`.

### 3. Автосумма наличных при оплате
- В окне оплаты, если способ **наличные** — поле «Дано» по умолчанию заполняется суммой чека (сдача = 0). Кассир может увеличить → сдача пересчитается.
- В **смешанной** оплате: ввёл нал → карта автоматом = `итог − нал` (это уже есть, оставляем/укрепляем).

### 4. Дашборд по сменам
- Раздел **Дашборд** для админа полностью перестраивается:
  - Экран №1 — список всех смен: дата, кассир, филиал, длительность, итог (нал/карта/микс), «Открыта/Закрыта».
  - Фильтры: филиал, кассир, дата от/до.
  - Клик по смене → Экран №2: подробности смены — все чеки, товары, оплаты, приход/расход, opening/closing cash, расхождение, графики за смену.
- Старый общий дашборд убираем.

### 5. Полный офлайн + APK
- **PWA-слой поверх сайта**: Service Worker кэширует shell (HTML/JS/CSS), картинки товаров и справочники (products, categories, branches). Продажи и отложенные чеки уже пишутся в Dexie и синкаются при появлении сети — расширим очередь на всё критичное.
- **APK через GitHub Actions**: чиню текущий workflow (у тебя есть коннектор GitHub — я могу читать логи прогонов и точечно править `.github/workflows/android-build.yml` до зелёного билда). APK будет grузить локально-закешированную PWA, так что офлайн работает и в APK, и в браузере.
